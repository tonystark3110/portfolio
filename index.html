agentns — Agent Name Service

DNS for AI agents. A sidecar service that lets agents register by label, and orchestrators resolve the healthiest, nearest replica at runtime. Think of it as service discovery purpose-built for multi-agent systems.

Agent registers → agentns → Returns best endpoint
Geo-aware ranking — haversine distance + health + latency + load
Three ANS roles in one binary: Namespace Server, Auth NS, Recursive Resolver
TTL cache, MongoDB persistence, asyncio health loop
120+ built-in city coords for geo routing with Nominatim fallback
